# Proxy Test

A simple Node.js + Express server with multi-user password access, one-device-per-password enforcement via cookies, and a Wisp/CDN proxy setup.

---

## Prerequisites

Make sure you have the following installed:

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) (comes with npm)

---

## Installation & Run

```bash
# 1. Clone the repository
git clone https://github.com/acmbc/proxyTest.git

# 2. Enter the project folder
cd proxyTest      # replace 'proxyTest' with your folder name if different

# 3. Install dependencies
npm install

# 4. Start the server
npm run start
